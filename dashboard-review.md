# Dashboard and guided practice checks

- Six configurable widgets: production bottlenecks, commercial exposure, supplier drift, follow-up queue, inbound/outbound freight mix and customer commitments.
- Preferences save per role perspective in browser storage; visibility, ordering, compact/expanded detail, analysis scope and reset are available.
- Widget actions open part details or focus the shortage board; clearing focus restores the board.
- Practice uses fictional, isolated fixtures. Three missions exercised end-to-end: freight comparison, confirmed supplier-delay extraction and approved customer push-out. Saved board data was identical immediately before and after all missions.
- Practice extraction is a prepared example, not a live AI call. Supplier request is an editable local draft; no email, transport booking or ERP changes occur.
- Freight figures reflect recorded modes, not real shipment tracking. Follow-up queue derives from stalled parts and customs holds; pending AI approvals or unsigned freight requests are not modeled.
- Desktop 1280px and phones 394px/320px checked: no page-wide horizontal overflow. Board retains bounded horizontal scrolling.
- Automated WCAG A/AA checks: zero axe violations on desktop, both phone sizes, customization drawer and supplier-update practice dialog. Practice controls measured at least 44px in each dimension.
- Manual screen-reader testing remains outstanding. Cloud sharing remains deferred to Phase 4.
